# Thisa Prime — Controle de Estoque v1

Primeira versão funcional de um sistema web de estoque.

## Como abrir
1. Extraia o ZIP.
2. Abra `index.html` no Google Chrome, Edge ou Firefox.
3. Login inicial:
   - Usuário: `admin`
   - Senha: `admin123`

## Recursos
- Dashboard
- Cadastro, edição e exclusão de materiais
- Estoque mínimo e alertas
- Entrada e saída de materiais
- Solicitações
- Histórico de alterações
- Cadastro de usuários e perfis
- Pesquisa
- Salvamento local no navegador (localStorage)

## Importante
Esta é uma versão inicial para validação da estrutura. Os dados ficam no navegador do computador utilizado e não são compartilhados automaticamente entre computadores.

Para uso real por toda a equipe, a próxima versão deve usar banco de dados e autenticação em servidor, permitindo que todos os usuários acessem o mesmo estoque pela rede/internet.
